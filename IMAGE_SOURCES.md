# Image Sources and Attribution

The website uses a web-sourced voter-service image for the hero visual.

1. Wikimedia Commons — `Voter Card.JPG`
   - Source page: https://commons.wikimedia.org/wiki/File:Voter_Card.JPG
   - The Commons page identifies the image as an Election Commission of India voter card and states that the image is public domain.
   - Direct file redirect used by the website: https://commons.wikimedia.org/wiki/Special:Redirect/file/Voter_Card.JPG

The website does not hotlink the image into a layout that depends on a third-party JavaScript library. If the source becomes unavailable, the surrounding CSS composition remains intact and the image element is visually collapsed by the included error handler, avoiding a broken-image icon or empty placeholder gap.

Before commercial launch, re-check the source page's current licensing/attribution terms and retain this file with the deployed site.
